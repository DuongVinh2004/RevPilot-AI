# RevPilot AI

RevPilot AI is an Autonomous Revenue Intelligence & Action Platform for Revenue Operations. The repository contains a bootstrap/shared-tenancy source baseline and a documentation pack. Current target status is `DOCUMENTATION CONTENT COMPLETE / IMPLEMENTATION PENDING / EMPIRICAL VALIDATION PENDING / GO-LIVE BLOCKED`. Historical Rail and test outcomes are not current execution evidence unless accompanied by a retained artifact from the release candidate. Implementation proceeds strictly via sequentially admitted micro-tasks under the Micro-Task Rail System; no work may bypass the rail or task-control system.

Start with [docs/README.md](docs/README.md), then read [docs/00-executive/DOCUMENTATION-CLOSURE-DECISIONS.md](docs/00-executive/DOCUMENTATION-CLOSURE-DECISIONS.md), [execution/CURRENT-STATE-RECONCILIATION.md](execution/CURRENT-STATE-RECONCILIATION.md), and [execution/OPEN-BLOCKERS.md](execution/OPEN-BLOCKERS.md).

## Non-negotiable product invariant

Every automated business action must be attributable to evidence, evaluated against policy, bounded in blast radius, idempotent where possible, and approved at the required risk tier.

## Lifecycle

`DETECT -> INVESTIGATE -> REASON -> VERIFY -> DECIDE -> APPROVE -> ACT -> MEASURE -> LEARN`
