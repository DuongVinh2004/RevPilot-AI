# RevPilot AI

RevPilot AI is an Autonomous Revenue Intelligence & Action Platform for Revenue Operations. The repository is currently in the design/specification stage; implementation must not start until Phase 00 exit criteria are approved.

Start with [docs/README.md](docs/README.md), then read [execution/MASTER-ROADMAP.md](execution/MASTER-ROADMAP.md).

## Non-negotiable product invariant

Every automated business action must be attributable to evidence, evaluated against policy, bounded in blast radius, idempotent where possible, and approved at the required risk tier.

## Lifecycle

`DETECT -> INVESTIGATE -> REASON -> VERIFY -> DECIDE -> APPROVE -> ACT -> MEASURE -> LEARN`
