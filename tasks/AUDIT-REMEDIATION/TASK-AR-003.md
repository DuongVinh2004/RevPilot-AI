## Implementation requirements

1. Create `scripts/collect-test-inventory.py`:
   - Import subprocess, datetime, pathlib, sys
   - Run `sys.executable + " -m pytest --collect-only -q"` capturing stdout/stderr
   - Parse last line for test count (regex: `(\d+) tests? collected`)
   - Get git commit SHA via `git rev-parse HEAD`
   - Get Python version via `sys.version`
   - Get pytest version via `pytest --version`
   - Write structured manifest to `execution/evidence/TEST-COLLECTION-MANIFEST.txt`
2. Update `execution/EXECUTOR-QUEUE.md`: Replace `1031/1031` with `See execution/evidence/TEST-COLLECTION-MANIFEST.txt for authoritative test count`.
3. Update `execution/RAIL-STATUS.md`: Replace `994/994` with `See execution/evidence/TEST-COLLECTION-MANIFEST.txt for authoritative test count`.
