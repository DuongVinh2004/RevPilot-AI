## Symbol-level contract

MUST EXPORT/DEFINE:
- `MetricType`: `RATIO`, `SUM`, `COUNT`, `AVG`
- `MetricGrain`: `HOURLY`, `DAILY`, `WEEKLY`, `MONTHLY`, `AS_OF_SNAPSHOT`
- `MetricDefinition(metric_id: str, name: str, version: str, metric_type: MetricType, unit: str, allowed_dimensions: List[str], calculate_fn: Callable)`
- `MetricRegistry`:
  - `register(metric: MetricDefinition) -> None`
  - `get(metric_id: str) -> Result[MetricDefinition, MetricNotFoundError]`
  - `list_metrics() -> List[MetricDefinition]`
  - `evaluate(metric_id: str, tenant_id: TenantId, data: MetricEvaluationDataset, as_of: UtcDateTime, filters: Optional[Dict[str, Any]]) -> Result[MetricValue, MetricEvaluationError]`
- Pre-populated registry singleton `CANONICAL_METRIC_REGISTRY` containing `METRIC-001` through `METRIC-009`.

MUST NOT:
- Permit evaluation of unknown metric names.
- Evaluate records with `event_time > as_of`.
- Aggregate across multiple tenants.

---

## Input/output and validation

INPUT: Metric ID, `TenantId`, entity dataset, `as_of` timestamp, optional dimension filters.
OUTPUT: `MetricValue(metric_id: str, tenant_id: TenantId, value: float | int, numerator: Optional[float], denominator: Optional[float], grain: MetricGrain, as_of: UtcDateTime)`.
VALIDATION:
- Denominator `0` on ratio metric returns `value = 0.0` with `is_zero_sample = True`.
- Filters only accepted for dimensions listed in `allowed_dimensions`.
