## Symbol-level contract

MUST EXPORT/DEFINE:
- `DatasetProfile`: Enum: `DEVELOPMENT`, `DEMO`, `INITIAL_COMMERCIAL`, `SCALE_GROWTH`
- `GeneratorConfig`:
  - `profile: DatasetProfile`
  - `seed: int`
  - `start_date: UtcDateTime`
  - `duration_days: int`
  - `tenants: List[TenantId]`
- `BenchmarkManifest`:
  - `manifest_id: str`
  - `generator_version: str`
  - `schema_version: str`
  - `scenario_version: str`
  - `profile: DatasetProfile`
  - `seed: int`
  - `artifact_hashes: Dict[str, str]` (file name to SHA-256)
- `SyntheticDataGenerator`:
  - `__init__(config: GeneratorConfig)`
  - `generate() -> GeneratedDatasetBundle`
- `GeneratedDatasetBundle`:
  - `customers: List[CustomerRecord]`
  - `orders: List[OrderRecord]`
  - `order_lines: List[OrderLineRecord]`
  - `shipments: List[ShipmentRecord]`
  - `support_tickets: List[SupportTicketRecord]`
  - `maintenance_events: List[MaintenanceEventRecord]`
  - `contracts: List[ContractRecord]`
  - `payment_references: List[PaymentReferenceRecord]`
  - `build_manifest() -> BenchmarkManifest`

MUST NOT:
- Use wall-clock time (`datetime.now()`).
- Use global non-seeded `random.random()`.
- Create cross-tenant references between `ten_alpha` and `ten_beta`.

## Input/output and validation

INPUT: `GeneratorConfig(profile=DatasetProfile.DEVELOPMENT, seed=42, ...)`.
OUTPUT: `GeneratedDatasetBundle` containing typed records and verified manifest.
VALIDATION:
- Generating twice with `seed=42` MUST yield identical SHA-256 checksums across all collections.
- `ten_alpha` entities must have zero IDs matching `ten_beta` entities.
