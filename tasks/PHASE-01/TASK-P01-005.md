## Symbol-level contract

MUST EXPORT/DEFINE:
- `RuleSeverity`: `CRITICAL`, `HIGH`, `MEDIUM`, `LOW`
- `ValidationResult`:
  - `is_valid: bool`
  - `rule_id: Optional[str]`
  - `error_code: Optional[str]`
  - `rejection_reason: Optional[str]`
- `DataQualityValidator`:
  - `validate_record(record: Dict[str, Any], session_tenant_id: TenantId) -> ValidationResult`
- `QuarantineRecord`:
  - `quarantine_id: str`
  - `tenant_id: TenantId`
  - `rule_id: str`
  - `raw_payload: Dict[str, Any]`
  - `rejection_reason: str`
  - `status: str` (QUARANTINED, REPROCESSED, DISCARDED)
  - `quarantined_at: UtcDateTime`
- `QuarantineRepository`:
  - `quarantine(record: QuarantineRecord) -> None`
  - `list_quarantined(tenant_id: TenantId) -> List[QuarantineRecord]`
  - `replay(quarantine_id: str, validator: DataQualityValidator) -> Result[Dict[str, Any], ValidationError]`
- `LineageRecord`:
  - `lineage_id: str`
  - `tenant_id: TenantId`
  - `source_system: str`
  - `source_batch_id: str`
  - `raw_payload_hash: str`
  - `transformation_name: str`
  - `record_counts: Dict[str, int]`

MUST NOT:
- Silently coerce negative currency values or out-of-range dates.
- Allow quarantined records to appear in canonical query results.
- Cross tenant boundaries when listing or replaying quarantine records.

---

## Input/output and validation

INPUT: Raw record dictionary, authenticated tenant ID.
OUTPUT: `ValidationResult(is_valid=True)` OR quarantine routing with structured error.
VALIDATION:
- Negative prices route to quarantine under `DQ-TYP-001`.
- Tenant mismatch routes to security quarantine under `DQ-TEN-001`.

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `DATA_QUALITY_VIOLATION` | Field/schema failure | 422 | no | Inbound record failed data quality checks | yes | `data_quality_rejections_total` |
| `TENANT_MISMATCH_DETECTED`| Record tenant != session | 403 | no | Cross-tenant injection attempt | yes | `security_tenant_mismatch_total` |

---

## Security contract

AUTHENTICATION: Required for quarantine inspection and replay.
AUTHORIZATION: Data platform operator or tenant admin.
TENANT: Quarantine records strictly isolated by `tenant_id` (`INV-TEN-001`).
PII: Raw payload in quarantine may contain customer PII; access is restricted and audited.
SECRET ACCESS: Prohibited.
DEFAULT: DENY.
