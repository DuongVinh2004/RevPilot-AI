## Symbol-level contract

MUST EXPORT/DEFINE:
- `TimeWindow(start_time: UtcDateTime, end_time: UtcDateTime)`
- `MetricQueryRequest(metric_id: str, metric_version: str, time_window: TimeWindow, grain: str, group_by_dimensions: List[str], filters: Dict[str, Any], as_of_time: UtcDateTime)`
- `MetricSeriesPoint(window_start: UtcDateTime, window_end: UtcDateTime, dimensions: Dict[str, str], actual_value: float, numerator_value: float, denominator_value: float, sample_size: int, is_zero_volume_sample: bool)`
- `MetricQueryResponse(query_id: str, metric_id: str, metric_name: str, metric_version: str, tenant_id: TenantId, grain: str, as_of_time: UtcDateTime, freshness_state: str, data_quality_state: str, lineage_snapshot_hash: str, series: List[MetricSeriesPoint])`
- `MetricService`:
  - `query(request: MetricQueryRequest, tenant_context: TenantContext) -> Result[MetricQueryResponse, MetricServiceError]`

MUST NOT:
- Permit caller to supply arbitrary SQL query text or unapproved aggregation expressions.
- Return any record whose `event_time > request.as_of_time`.
- Allow client-side tenant override headers.
- Raise `ZeroDivisionError` when denominator is 0.

---

## Input/output and validation

INPUT: Typed `MetricQueryRequest` and cryptographically validated `TenantContext`.
OUTPUT: Typed `MetricQueryResponse` containing aggregated time-series points.
VALIDATION:
- Denominator = 0 returns `actual_value = 0.0` and `is_zero_volume_sample = true`.
- Request with unapproved dimension returns `Err(INVALID_DIMENSION_FILTER)`.
- Request with future `as_of_time` returns `Err(TEMPORAL_LEAKAGE_REJECTED)`.

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `METRIC_NOT_REGISTERED` | Metric ID missing from registry | 404 | no | Unknown metric identifier | no | `metric_registry_errors_total` |
| `INVALID_DIMENSION_FILTER`| Requested dimension not allowed | 400 | no | Dimension not permitted for metric | no | `metric_dimension_errors_total` |
| `TEMPORAL_LEAKAGE_REJECTED`| As-of watermark is in future | 422 | no | Future as-of timestamp rejected | yes | `metric_temporal_violations_total` |
| `TENANCY_VIOLATION` | Tenant token mismatch | 403 | no | Cross-tenant access denied | yes | `metric_tenant_violations_total` |
