## Objective and rationale

OBJECTIVE: Implement deterministic statistical time-series baselines (`SeasonalNaiveBaseline`, `RollingStatsBaseline`, `EwmaBaseline`) in `packages/backend/src/revpilot/modules/analytics/baselines/` to produce historical expectations and calibrated prediction intervals without using LLMs or complex external runtimes.

BUSINESS RATIONALE: Provide an objective, reproducible statistical benchmark against which advanced anomaly detectors and causal uplift estimators are quantitatively compared (`FR-DET-002`, `FR-ML-001`, `NFR-AI-004`, `AC-002`).

## Symbol-level contract

MUST EXPORT/DEFINE:
- `BaselinePrediction(point_estimate: float, lower_bound: float, upper_bound: float, baseline_id: str, baseline_version: str)`
- `SeasonalNaiveBaseline(season_length: int = 7, alpha: float = 0.05)`:
  - `predict(series: List[float]) -> BaselinePrediction`
- `RollingStatsBaseline(window_size: int = 14, iqr_multiplier: float = 1.5)`:
  - `predict(series: List[float]) -> BaselinePrediction`
- `EwmaBaseline(alpha: float = 0.2, sigma_multiplier: float = 3.0)`:
  - `predict(series: List[float]) -> BaselinePrediction`

MUST NOT:
- Look ahead into future values beyond the supplied index.
- Import LLM libraries or invoke external web services.
- Return `NaN` or unhandled exceptions when series contains zeroes or empty windows.

---

## Input/output and validation

INPUT: Chronological list of float metric values.
OUTPUT: Typed `BaselinePrediction` with point estimate and prediction interval bounds.
VALIDATION:
- Seasonal Naive on 14-day test vector predicts $Y_t = Y_{t-7}$.
- Empty series returns `point_estimate = 0.0` with `[0.0, 0.0]` bounds.
