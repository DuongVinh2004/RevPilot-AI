- `RollingTimeSplitEvaluator`:
  - `run_backtest(tenant_id: TenantId, metric_id: str, detector: StlResidualDetector, start_day: int, end_day: int, ground_truth_path: str) -> DetectorBenchmarkMetrics`

- Allow `StlResidualDetector` to read ground-truth files or incident annotations.
- Include data points where `event_time > current_step_as_of` during the rolling backtest.
- Fabricate benchmark metrics without executing real iterations.
