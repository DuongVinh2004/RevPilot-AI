## Input/output and validation

INPUT:
```python
Investigation(
    investigation_id=UUIDv7(),
    tenant_id=TenantId("ten_01h8abcde12345"),
    principal_id=PrincipalId("usr_01h8abcde99999"),
    metric_name="order_cancellation_rate",
    anomaly_id=AnomalyId("anm_01h8abcde11111"),
    scope=InvestigationScope(region="US-EAST"),
    window_start=UtcDateTime.parse("2026-05-10T00:00:00Z"),
    window_end=UtcDateTime.parse("2026-05-17T00:00:00Z"),
    as_of_time=UtcDateTime.parse("2026-05-18T00:00:00Z"),
    status=InvestigationStatus.INITIALIZING,
    budget=BudgetState()
)
```
OUTPUT: Validated in-memory aggregate.
INVALID INPUT:
- `window_end > as_of_time` -> throws `TemporalValidationException`.
- `budget.spent_usd > Decimal("5.00")` -> raises `BudgetExceededError`.
- Direct jump from `INITIALIZING` to `COMPLETED` -> returns `Err(INVALID_STATE_TRANSITION)`.

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `ERR_INVALID_STATE_TRANSITION` | Disallowed lifecycle jump | 409 | no | Invalid investigation state transition | yes | `investigation.state_error` |
| `ERR_BUDGET_EXCEEDED` | Spend reaches $5.00 USD | 429 | no | Investigation budget exhausted | yes | `investigation.budget_exhausted` |
| `ERR_TEMPORAL_LEAKAGE` | Window end > as of time | 400 | no | Temporal window violates as_of boundary | yes | `investigation.temporal_leak` |
