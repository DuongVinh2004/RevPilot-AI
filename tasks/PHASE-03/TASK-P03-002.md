## Symbol-level contract

MUST EXPORT/DEFINE:
- `revpilot.modules.investigation.workflows.investigation_workflow`:
  - `@workflow.defn class InvestigationWorkflow`:
    - `@workflow.run async def run(self, input_data: InvestigationWorkflowInput) -> InvestigationManifest`
    - `@workflow.signal def pause_investigation(self, signal: PauseInvestigationSignal)`
    - `@workflow.signal def resume_investigation(self, signal: ResumeInvestigationSignal)`
    - `@workflow.signal def cancel_investigation(self, signal: CancelInvestigationSignal)`

  - Typed activity interfaces for `ValidateInvestigationScopeActivity`, `GenerateInvestigationPlanActivity`, `ExecuteReadOnlySqlCapabilityActivity`, `ExecuteGovernedRetrievalActivity`, `IngestTicketIntelligenceActivity`, `SynthesizeHypothesesActivity`, `VerifyEvidenceAndHypothesesActivity`, `PackageEvidenceBundleActivity`.

MUST NOT:
- Execute non-deterministic code (clock, random, network, DB) inside workflow definition body (`INV-WF-002`).
- Call external mutation adapters in activities (`INV-ACT-001`).

## Operational behavior

RETRY: Activities follow `TRANSIENT_ACTIVITY_RETRY_POLICY` (max 2 attempts, backoff 2.0).
TIMEOUT: WorkflowRunTimeout = 600s, ActivityScheduleToClose = 10–45s.
IDEMPOTENCY: Guaranteed by Temporal Workflow ID per investigation.
LOGGING: Structured workflow life-cycle events.
METRICS: `temporal_workflow_execution_duration_seconds`, `temporal_activity_failure_count`.
FAILURE BEHAVIOR: Transitions to `FAILED`, persists error context, notifies caller.
