## Symbol-level contract

MUST EXPORT/DEFINE:
- `revpilot.modules.analytics.capabilities.catalog`:
  - `REGISTERED_SQL_CAPABILITIES: Dict[str, SqlCapabilityDefinition]`
  - Contains all 7 capabilities: `CAP-SQL-DRILLDOWN-DIM`, `CAP-SQL-METRIC-TIMESERIES`, `CAP-SQL-SEGMENT-COMPARE`, `CAP-SQL-SHIPMENT-DELAY`, `CAP-SQL-TICKET-VOLUME`, `CAP-SQL-MAINTENANCE-WINDOW`, `CAP-SQL-CONTRACT-SLA`.
- `revpilot.modules.analytics.capabilities.executor`:
  - `class SqlCapabilityExecutor`:
    - `async def execute(self, request: CapabilityRequest, db_session: AsyncSession) -> Result[CapabilityResult, CapabilityError]`
- `revpilot.modules.analytics.capabilities.templates`:
  - Parameterized SQL builders with strictly static clauses and parameterized binding.

MUST NOT:
- Accept raw string SQL input from caller (`FR-INV-004`).
- Allow `DROP`, `ALTER`, `CREATE`, `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE` (`INV-ACT-001`).
- Query any table not present in the capability definition (`INV-SEC-003`).

## Input/output and validation

INPUT:
```python
CapabilityRequest(
    capability_id="CAP-SQL-DRILLDOWN-DIM",
    tenant_context=TenantContext(tenant_id=TenantId("ten_01h8abcde12345")),
    principal_context=PrincipalContext(principal_id=PrincipalId("usr_01h8abc")),
    investigation_id=UUIDv7(),
    as_of_time=UtcDateTime.parse("2026-05-18T00:00:00Z"),
    parameters={
        "metric_name": "order_cancellation_rate",
        "dimension": "carrier_code",
        "start_time": "2026-05-10T00:00:00Z",
        "end_time": "2026-05-17T00:00:00Z"
    },
    budget_remaining_usd=Decimal("2.00")
)
```
OUTPUT:
`CapabilityResult` with aggregated rows (max 100), `execution_time_ms`, row digest, and cost.
VALIDATION RULES:
- Reject dimension if not in allowlist (`region`, `carrier_code`, `warehouse_id`, etc.).
- Reject request if `end_time > as_of_time` (`INV-DATA-001`).

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `ERR_UNREGISTERED_CAPABILITY` | Unknown capability ID | 404 | no | Capability not found in registry | yes | `capability.unregistered` |
| `ERR_PROHIBITED_SQL_OPERATION` | DDL/DML keyword detected | 403 | no | Operation forbidden by read-only policy | yes | `security.sql_violation` |
| `ERR_DISALLOWED_DIMENSION` | Dimension outside allowlist | 400 | no | Dimension not permitted for metric | yes | `analytics.invalid_dimension` |
| `ERR_QUERY_TIMEOUT` | Exceeds 5,000 ms timeout | 504 | no | Capability execution timed out | yes | `analytics.query_timeout` |

## Security contract

AUTHENTICATION: Required via `PrincipalContext`.
AUTHORIZATION: Scope `analytics:query`.
TENANT: Mandatory server-injected `:tenant_id` predicate and RLS context.
PII: Masked or excluded from projection.
SECRET ACCESS: Strictly prohibited.
EXTERNAL ACTION: Strictly prohibited.
DEFAULT: DENY.

---

## Operational behavior

RETRY: 1 retry for transient DB connection drops; 0 retries for validation or security errors.
TIMEOUT: 5,000 ms statement timeout enforced.
IDEMPOTENCY: Query digest provides caching key.
LOGGING: Logs query execution duration, row count, and digest (no PII).
METRICS: `sql_capability_duration_seconds`, `sql_capability_rows_returned`.
FAILURE BEHAVIOR: Returns typed `CapabilityResult(status="FAILED", error_code=...)`.
