## Symbol-level contract

MUST EXPORT/DEFINE:
- `revpilot.modules.evidence.domain.models`:
  - `SourceSystemType`, `ClassificationLevel`, `SupersessionStatus`, `ExtractionMethod`, `RetrievalMethod`.
  - `CitationSpan(BaseModel)`: `chunk_id`, `section_id`, `start_char`, `end_char`, `snippet_text`.
  - `EvidenceRecord(BaseModel)`: Complete schema from `EVIDENCE-PROVENANCE-SPEC.md` §2.
  - `EvidenceBundle(BaseModel)`: `bundle_id`, `investigation_id`, `tenant_id`, `evidence_count`, `evidence_items`, `bundle_digest`, `sealed_at`.
- `revpilot.modules.evidence.domain.temporal_filter`:
  - `is_evidence_temporally_valid(record: EvidenceRecord, as_of_time: UtcDateTime) -> bool`:
    Evaluates `effective_time <= as_of_time AND (expiration_time IS NULL OR expiration_time > as_of_time) AND (supersession_status == ACTIVE OR (superseded_at > as_of_time))`.
- `revpilot.modules.evidence.domain.packaging`:
  - `package_evidence_bundle(investigation_id: UUIDv7, tenant_id: TenantId, records: List[EvidenceRecord]) -> Result[EvidenceBundle, PackagingError]`

MUST NOT:
- Package evidence records with mismatched `tenant_id` into the same bundle (`INV-TEN-001`).
- Include records with `supersession_status == SUPERSEDED` where `superseded_at <= as_of_time` (`INV-EVD-002`).

## Input/output and validation

INPUT: List of `EvidenceRecord` candidates gathered from queries or document search.
OUTPUT: Sealed `EvidenceBundle` with SHA-256 `bundle_digest`.
VALIDATION RULES:
- `content_digest` must equal `SHA256(canonical_serialize(payload))`.
- If any item fails ACL or effective-date check, packaging rejects or excludes the item.

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `ERR_CROSS_TENANT_EVIDENCE` | Multi-tenant records in bundle | 403 | no | Cross-tenant evidence mixing detected | yes | `evidence.cross_tenant_block` |
| `ERR_EVIDENCE_SUPERSEDED` | Clause superseded at as_of_time | 400 | no | Evidence is superseded or inactive | yes | `evidence.superseded_block` |
| `ERR_DIGEST_MISMATCH` | Payload hash mismatch | 500 | no | Evidence content digest verification failed | yes | `evidence.tamper_detected` |
