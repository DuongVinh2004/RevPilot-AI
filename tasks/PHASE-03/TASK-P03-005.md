  - `verify_citation_span(source_text: str, span: CitationSpan) -> bool`:

  - `sanitize_and_frame_document(chunk_text: str, source_id: str) -> str`:
    Wraps text in `<untrusted_document>` tags; scores injection likelihood.

- Permit retrieval across tenant boundaries under any circumstances (`INV-TEN-001`).
- Return citations where character offsets do not match exact source bytes (`AC-004`).
- Allow prompt injection payloads to strip containment delimiters (`INV-SEC-002`).

## Input/output and validation

INPUT:
`RetrievalQuery` with `query_text`, `tenant_context`, `principal_context`, `filters` (effective_at, as_of_time, classification_max), and `top_k`.
OUTPUT:
List of validated `RetrievedEvidenceChunk` objects with fused scores and verified citation spans.
VALIDATION RULES:
- `filters.as_of_time` enforced on document chunks (`effective_from <= as_of_time`).
- Chunks flagged with high injection risk are quarantined.
