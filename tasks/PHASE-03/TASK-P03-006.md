## Input/output and validation

INPUT: `EvidenceBundle` containing verified query metrics and document excerpts.
OUTPUT: `VerificationResult` containing ranked hypotheses with verified citations, evidence coverage ratio, and verdict (`VERIFIED`, `REFUTED`, or `NEED_MORE_EVIDENCE`).
VALIDATION RULES:
- Every supporting evidence ID in a `Hypothesis` must exist in `EvidenceBundle`.
- If evidence coverage ratio < 0.70 or key dimensions lack evidence, verdict is `NEED_MORE_EVIDENCE` (`FR-RCA-002`).

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `ERR_DAG_CYCLE_DETECTED` | Plan contains cyclical tasks | 422 | no | Cyclical task dependency detected | yes | `agent.dag_cycle` |
| `ERR_DAG_LIMIT_EXCEEDED` | Depth > 4 or tasks > 20 | 422 | no | Plan exceeds complexity bounds | yes | `agent.dag_limit` |
| `ERR_UNSUPPORTED_CLAIMS` | Hypothesis lacks evidence | 422 | no | Hypothesis rejected: unsupported claims | yes | `ai.unsupported_claim` |

## Operational behavior

RETRY: Verifier is deterministic; 0 retries. Planner transient model error: max 1 retry.
TIMEOUT: Planner 30s timeout; Verifier 10s timeout.
IDEMPOTENCY: Governed by `investigation_id`.
LOGGING: Structured evaluation events without prompt dumps.
METRICS: `agent_plan_task_count`, `agent_unsupported_claim_count`, `verifier_verdict_count`.
FAILURE BEHAVIOR: Emits `NEED_MORE_EVIDENCE` or returns typed error.
