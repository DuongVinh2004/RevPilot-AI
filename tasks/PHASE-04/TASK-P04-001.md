## 7. Failure, Retry, Timeout, and Idempotency

- If evidence bundle is empty or coverage < 0.75, status transitions deterministically to `NEED_MORE_EVIDENCE` (`FR-RCA-002`).
- If an authoritative contradiction is linked ($S_{\text{con}} \ge 0.80$), status transitions to `REFUTED`.
- Ranking calculation is pure and deterministic (time limit <= 200ms for 20 candidate hypotheses).

---

## 8. Security, Tenancy, and Privacy Contract

- Enforce `INV-TEN-001..003`: Every hypothesis record contains `tenant_id`. Cross-tenant evidence links are rejected with `ERR_TENANT_MISMATCH`.
- Enforce `INV-AI-001`: Unsupported claims or ungrounded hypotheses receive status `UNSUPPORTED`.
- Enforce `AC-013`: API serialization suppresses internal prompt chains and hidden CoT.
