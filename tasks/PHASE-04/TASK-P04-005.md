## 7. Failure, Retry, Timeout, and Idempotency

- If $|\widehat{\text{ATE}} - 0.0660| > 0.0500$, benchmark fails `GATE-CAUSAL-ATE-ERR` (`NFR-AI-007`).
- If Midwest truck capacity is not ranked #1, benchmark fails `GATE-RCA-TOP1` (`NFR-AI-002`).
- Benchmark run records metrics to an immutable dated `EvalRun` artifact with SHA-256 digest.
