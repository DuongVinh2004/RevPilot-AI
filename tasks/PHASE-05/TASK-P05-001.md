## Symbol-level contract

```python
class ChurnPredictionRecord(BaseModel):
    prediction_id: UUIDv7
    tenant_id: TenantId
    customer_id: str
    as_of_time: UtcDateTime
    model_artifact_id: str
    calibrated_probability: float
    risk_tier: Literal["LOW", "MEDIUM", "HIGH", "CRITICAL"]
    ece_at_release: float
    feature_snapshot_digest: str
    is_treatment_contaminated: bool
    created_at: UtcDateTime

class ProbabilityCalibrator:
    def fit(self, y_true: np.ndarray, y_prob: np.ndarray, method: Literal["PLATT", "ISOTONIC"]) -> None: ...
    def predict_proba(self, y_prob: np.ndarray) -> np.ndarray: ...
    def compute_ece(self, y_true: np.ndarray, y_prob: np.ndarray, n_bins: int = 10) -> float: ...

class ChurnScoringService:
    async def score_account(self, ctx: TenantContext, customer_id: str, as_of_time: UtcDateTime) -> ChurnPredictionRecord: ...
```

## Non-functional and security invariants

- `INV-TEN-001`: Every scoring execution scopes query strictly to authenticated tenant context.
- `INV-DATA-001`: As-of watermark prevents lookahead; features after `as_of_time` raise `ERR_TEMPORAL_LEAKAGE`.
- `NFR-AI-005`: Time-split holdout Expected Calibration Error $\le 0.0500$.
- `INV-AI-001`: Churn score output includes explicit metadata that it is NOT a causal treatment effect.

## Binary acceptance criteria

- [ ] All 5 test files execute cleanly and pass with 0 failures (`TC-P05-001..005`).
- [ ] Expected Calibration Error on 10-bin split is strictly $\le 0.0500$ (`NFR-AI-005`).
- [ ] Accounts receiving retention treatments in the evaluation window are flagged `is_treatment_contaminated = True`.
- [ ] Zero feature leakage: synthetic records timestamped $> \text{as\_of\_time}$ cause failure.
- [ ] Read-only tenant isolation: Tenant A cannot predict or retrieve scores for Tenant B.

## Rollback and recovery

If calibration fails or ECE $> 0.05$, the model service reverts to fallback baseline `BASE-ROLLING-STATS-001` and halts promotion.
