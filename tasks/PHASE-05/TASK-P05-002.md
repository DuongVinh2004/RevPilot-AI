## Non-functional and security invariants

- `INV-AI-001`: Output contains non-removable disclaimer: *"Feature attributions describe model statistical associations, not real-world causal mechanisms."*
- `INV-PRV-001`: Any feature tagged with PII is strictly excluded or anonymized before returning attributions.
- Deterministic Ordering: Top features are sorted deterministically by absolute attribution value descending, then lexicographically by feature name.
