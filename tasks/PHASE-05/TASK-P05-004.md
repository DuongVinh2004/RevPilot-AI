## Symbol-level contract

```python
class BudgetLedgerEntry(BaseModel):
    tenant_id: TenantId
    ledger_date: UtcDate
    total_allocated_usd: Decimal
    committed_expenditure_usd: Decimal
    remaining_balance_usd: Decimal
    version: int

class ConstraintEvaluationOutcome(BaseModel):
    is_eligible: bool
    passed_constraints: List[str]
    violated_constraints: List[str]
    evaluated_at: UtcDateTime

class HardConstraintEvaluator:
    def evaluate(self, ctx: TenantContext, customer_id: str, candidate: CandidateIntervention, budget_ledger: BudgetLedgerEntry) -> ConstraintEvaluationOutcome: ...

class BudgetLedgerService:
    async def reserve_budget(self, ctx: TenantContext, amount_usd: Decimal, date: UtcDate) -> Tuple[bool, BudgetLedgerEntry]: ...
```

## Non-functional and security invariants

- `AC-007`: Hard constraints are evaluated prior to utility ranking; violating candidates are filtered out immediately.
- `INV-COST-001`: Daily budget cannot be overdrawn; reservation requests exceeding balance fail closed with `ERR_BUDGET_EXCEEDED`.
- `INV-REL-001`: Missing or unresolvable policy state fails closed with `ERR_POLICY_UNKNOWN`.
- `INV-TEN-001`: Budget ledgers and customer history are strictly partitioned by `tenant_id`.

## Rollback and recovery

If budget reservation fails or deadlocks, reservation transaction aborts, leaves committed ledger unchanged, and returns `ERR_BUDGET_RESERVATION_FAILED`.
