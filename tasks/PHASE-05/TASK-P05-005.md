```python
class DecisionRequest(BaseModel):
    request_id: UUIDv7
    tenant_id: TenantId
    customer_id: str
    investigation_id: Optional[UUIDv7]
    as_of_time: UtcDateTime
    candidates: List[CandidateIntervention]
    customer_arr_usd: Decimal
    allocated_budget_usd: Decimal
    remaining_capacity: int

class RecommendationRecord(BaseModel):
    recommendation_id: UUIDv7
    request_id: UUIDv7
    tenant_id: TenantId
    selected_candidate_id: Optional[str]
    expected_utility_usd: Decimal
    expected_incremental_retention_rate: float
    direct_cost_usd: Decimal
    risk_penalty_usd: Decimal
    uncertainty_penalty_usd: Decimal
    confidence_interval_95: Tuple[float, float]
    ranked_alternatives: List[Dict[str, Any]]
    ineligible_candidates: Dict[str, List[str]]
    status: Literal["RECOMMENDED", "ABSTAINED", "NEED_MORE_EVIDENCE", "BLOCKED"]
    decision_digest: str
    created_at: UtcDateTime

class DecisionOptimizerService:
    async def optimize_decision(self, ctx: TenantContext, req: DecisionRequest) -> RecommendationRecord: ...
    async def simulate_budget(self, ctx: TenantContext, cohort_id: str, scenarios: List[Decimal]) -> Dict[str, Any]: ...
```

## Non-functional and security invariants

- `AC-007`: Hard constraints strictly evaluated before utility calculation. Ineligible candidates cannot be ranked.
- `INV-ACT-001`: Optimization produces recommendation artifact only; zero physical write tool invocations.
- Abstention Invariant: If $\mathbb{E}[U(a)] \le 0$ for all candidates, optimizer returns `ABSTAINED` with `selected_candidate_id = None`.
- Deterministic Tie-Breaking: Strict resolution order: lower cost, lower uncertainty, lexicographical candidate ID.
