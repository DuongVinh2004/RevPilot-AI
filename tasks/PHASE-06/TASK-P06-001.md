OBJECTIVE: Implement the Approval Request domain aggregate, cryptographic SHA-256 payload digest sealing, state machine lifecycle, and amendment supersession.
BUSINESS RATIONALE: High-impact actions require an unforgeable, tamper-evident approval request ensuring that human approvers sign the exact payload, target set, and cost that will be executed (`INV-ACT-002`, `AC-008`).
ARCHITECTURAL OWNER: Policy & Approval Architecture (`revpilot.modules.approval`)
ARCHITECTURAL CONTEXT: Consumes `RecommendationRecord`. Produces `ApprovalRequestRecord` and persists to `approval_requests` table.

## Symbol-level contract

```python
class ApprovalStatus(str, Enum):
    DRAFT = "DRAFT"
    PENDING = "PENDING"
    APPROVED = "APPROVED"
    REJECTED = "REJECTED"
    AMENDED = "AMENDED"
    EXPIRED = "EXPIRED"
    REVOKED = "REVOKED"
    SUPERSEDED = "SUPERSEDED"

class ApprovalRequestRecord(BaseModel):
    approval_id: UUIDv7
    tenant_id: TenantId
    decision_id: UUIDv7
    investigation_id: Optional[UUIDv7]
    action_type: str
    action_version: str = "1.0.0"
    target_customer_id: str
    target_entity_refs: List[str]
    action_payload: Dict[str, Any]
    payload_digest: str
    policy_digest: str
    estimated_cost_usd: Decimal
    reserved_budget_usd: Decimal
    risk_tier: Literal["LOW", "MEDIUM", "HIGH", "CRITICAL"]
    required_approval_tier: int
    approver_principal_id: Optional[str]
    approval_timestamp: Optional[UtcDateTime]
    expiry_time: UtcDateTime
    status: ApprovalStatus
    decision_digest: str
    created_at: UtcDateTime

class ApprovalDigestHasher:
    @staticmethod
    def compute_payload_digest(action_type: str, target_entities: List[str], payload: Dict[str, Any], cost_usd: Decimal) -> str: ...

class ApprovalService:
    async def create_request(self, ctx: TenantContext, rec: RecommendationRecord) -> ApprovalRequestRecord: ...
    async def grant_approval(self, ctx: TenantContext, approval_id: UUIDv7, expected_digest: str) -> ApprovalRequestRecord: ...
    async def amend_request(self, ctx: TenantContext, approval_id: UUIDv7, new_payload: Dict[str, Any]) -> ApprovalRequestRecord: ...
```

## Non-functional and security invariants

- `INV-ACT-002`: Action execution requires exact SHA-256 match against `payload_digest`. Tampering with any byte raises `ERR_APPROVAL_DIGEST_MISMATCH`.
- `INV-TEN-001`: Strict isolation; Tenant A cannot view, approve, or amend Tenant B requests.
- Expiration: Requests past 24h TTL automatically transition to `EXPIRED` and fail closed.
- Replay Protection: Executed approvals cannot be reused (`ERR_ALREADY_USED`).
