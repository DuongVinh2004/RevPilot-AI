## Symbol-level contract

```python
class ApprovalTier(IntEnum):
    TIER_1_OPERATIONAL = 1              # <= $250.00
    TIER_2_TACTICAL = 2                 # <= $1,000.00
    TIER_3_EXECUTIVE = 3                # Unbounded / <= $10,000.00

class RevalidationCheckpoint(str, Enum):
    PRE_CREATION = "PRE_CREATION"
    ON_SUBMISSION = "ON_SUBMISSION"
    ON_APPROVAL = "ON_APPROVAL"
    PRE_DRY_RUN = "PRE_DRY_RUN"
    PRE_DISPATCH = "PRE_DISPATCH"
    POST_RESULT = "POST_RESULT"

class PolicyRevalidationService:
    def verify_approver_authority(self, principal: PrincipalContext, cost_usd: Decimal, tier: int) -> bool: ...
    def check_separation_of_duties(self, proposer_id: str, approver_id: str, cost_usd: Decimal) -> bool: ...
    async def revalidate(self, ctx: TenantContext, approval: ApprovalRequestRecord, checkpoint: RevalidationCheckpoint) -> Result[None, PolicyViolationError]: ...
```

## Non-functional and security invariants

- `INV-ACT-003`: Agent identities calling approval endpoints are rejected with `ERR_AGENT_SELF_APPROVAL` (403).
- Separation of Duties: Proposer cannot approve their own action when cost $> \$250.00$.
- Six-Point Revalidation: If policy changes between approval and dispatch, the dispatch gate rejects execution (`ERR_POLICY_STALE`).
- Fail-Closed: Policy engine outage or network timeout causes immediate rejection (`ERR_POLICY_UNAVAILABLE`).
