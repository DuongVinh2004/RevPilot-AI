## Objective and rationale

OBJECTIVE: Implement the dry-run simulation engine, `ActionIntentRecord` creation, and durable `ActionLedgerRecord` state machine with strict tenant-scoped idempotency.
BUSINESS RATIONALE: Operators must be able to inspect simulated side effects before execution, and all physical executions must be tracked in an immutable, idempotent ledger to prevent double dispatch (`INV-ACT-001`, `AC-009`).
ARCHITECTURAL OWNER: Action Safety Architecture (`revpilot.modules.action.ledger`)
ARCHITECTURAL CONTEXT: Consumes approved `ApprovalRequestRecord`. Manages `action_intents` and `action_ledgers` tables.

## Symbol-level contract

```python
class ActionIntentRecord(BaseModel):
    intent_id: UUIDv7
    tenant_id: TenantId
    approval_id: UUIDv7
    idempotency_key: str
    action_type: str
    classification: ActionClassification
    target_set_count: int
    payload_digest: str
    is_dry_run: bool
    status: Literal["INITIALIZED", "DISPATCHED", "COMPLETED", "FAILED", "RECONCILING"]
    created_at: UtcDateTime

class ActionLedgerRecord(BaseModel):
    ledger_id: UUIDv7
    tenant_id: TenantId
    intent_id: UUIDv7
    attempt_number: int
    idempotency_key: str
    provider_name: str
    request_digest: str
    response_digest: Optional[str]
    http_status_code: Optional[int]
    provider_tx_id: Optional[str]
    execution_status: Literal["STARTED", "SUCCESS", "PROVIDER_ERROR", "TIMEOUT_UNKNOWN", "RECONCILED", "COMPENSATED"]
    started_at: UtcDateTime
    completed_at: Optional[UtcDateTime]

class ActionLedgerService:
    async def execute_dry_run(self, ctx: TenantContext, intent: ActionIntentRecord) -> Dict[str, Any]: ...
    async def record_attempt_start(self, ctx: TenantContext, intent_id: UUIDv7, idempotency_key: str, request_digest: str) -> ActionLedgerRecord: ...
    async def record_attempt_completion(self, ctx: TenantContext, ledger_id: UUIDv7, status: str, response_digest: Optional[str], tx_id: Optional[str]) -> ActionLedgerRecord: ...
```

## Non-functional and security invariants

- `AC-009`: Dry-run mode evaluates identical validation logic, strictly prohibiting any external socket or side-effect dispatch.
- `INV-ACT-001`: Idempotency keys are unique per `(tenant_id, idempotency_key)`. Duplicate submissions return existing intent.
- Ledger Integrity: Action ledger records attempt number and SHA-256 request/response digests.
