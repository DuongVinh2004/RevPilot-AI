## Symbol-level contract

```python
class KillSwitchScope(str, Enum):
    GLOBAL = "GLOBAL"
    TENANT = "TENANT"
    CAPABILITY = "CAPABILITY"
    PROVIDER = "PROVIDER"
    INVESTIGATION = "INVESTIGATION"

class KillSwitchRecord(BaseModel):
    switch_id: UUIDv7
    scope: KillSwitchScope
    target_id: Optional[str]
    is_active: bool
    reason: str
    activated_by: str
    activated_at: UtcDateTime

class KillSwitchService:
    async def activate(self, scope: KillSwitchScope, target_id: Optional[str], reason: str, principal: str) -> KillSwitchRecord: ...
    async def is_blocked(self, tenant_id: TenantId, capability: str, provider: str, investigation_id: Optional[UUIDv7]) -> bool: ...

class BlastRadiusLimiter:
    def check_limits(self, target_count: int, estimated_cost_usd: Decimal, tier: int) -> Result[None, BlastRadiusExceededError]: ...
```

## Non-functional and security invariants

- `INV-REL-001`: Kill switch state propagates to all gateway instances in $< 500\text{ms}$.
- Agent Non-Overridable: AI agents cannot deactivate kill switches or bypass `is_blocked()` evaluations.
- Blast Radius Limit: Any single action targeting $> 500$ entities or exceeding tier budget fails closed with `ERR_BLAST_RADIUS_EXCEEDED`.
