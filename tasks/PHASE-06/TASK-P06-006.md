## Symbol-level contract

```python
class CompensationStatus(str, Enum):
    PENDING = "PENDING"
    COMPLETED = "COMPLETED"
    FAILED_MANUAL_REQUIRED = "FAILED_MANUAL_REQUIRED"

class CompensationRecord(BaseModel):
    record_id: UUIDv7
    tenant_id: TenantId
    intent_id: UUIDv7
    step_name: str
    compensation_action: str
    status: CompensationStatus
    compensated_at: UtcDateTime

class SafeActionSagaWorkflow:
    async def execute_action_saga(self, intent: ActionIntentRecord) -> ActionLedgerRecord: ...
    async def compensate_steps(self, completed_steps: List[Tuple[str, Dict[str, Any]]]) -> None: ...
    async def reconcile_unknown(self, intent: ActionIntentRecord, ledger_id: UUIDv7) -> ActionLedgerRecord: ...
```

## Non-functional and security invariants

- `NFR-REL-001`: Zero blind retries on `UNKNOWN`. Timeouts immediately transition to status inquiry activities using provider idempotency keys.
- Irreversible Actions: Actions marked `IRREVERSIBLE` (e.g. physical carrier truck dispatch) cannot execute automated compensation; workflow flags manual intervention required.
- Saga Rollback Order: Steps are compensated in strict reverse chronological order of their successful execution.

## Rollback and recovery

If a compensation activity fails, status updates to `FAILED_MANUAL_REQUIRED` and immediately pages on-call operations.
