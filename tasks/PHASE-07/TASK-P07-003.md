## Objective and rationale

OBJECTIVE: Implement SAML 2.0 Assertion Consumer Service (ACS) with XML digital signature verification and dual-certificate rotation, alongside SCIM 2.0 automated user and group lifecycle provisioning and rapid session deprovisioning endpoints.
BUSINESS RATIONALE: Legacy enterprise pilot customers mandate SAML 2.0 for SSO and SCIM 2.0 to automate user onboarding and immediate deprovisioning upon employee offboarding (`BR-004`, `INV-IAM-001`, `INV-TEN-002`).
ARCHITECTURAL OWNER: Security Architecture / IAM (`revpilot.modules.iam.federation`)
ARCHITECTURAL CONTEXT: Complements OIDC baseline with SAML and SCIM protocols.

MUST NOT: Accept unsigned SAML assertions, permit XML Signature Wrapping (XSW) attacks, or delay SCIM session revocation beyond 1000ms.

## Input/output and validation

INPUT: Base64-encoded SAMLResponse, SCIM JSON envelopes conforming to RFC 7643.
OUTPUT: Authenticated `PrincipalContext` or updated SCIM resource representations.
INVALID INPUT: Forged SAML XML, expired assertion timestamps, malformed SCIM schemas.
VALIDATION RULES: Strict schema validation and digital signature check against active X.509 certificate.
STATE TRANSITIONS: SCIM deprovisioning sets `status = DEACTIVATED` and immediately revokes all active sessions.

## Security contract

AUTHENTICATION: Enforces SAML SSO or SCIM Bearer token authentication.
AUTHORIZATION: Scoped strictly per tenant; SCIM tokens are tenant-partitioned.
TENANT: Multi-tenant isolated; SCIM URLs include `{tenant_id}`.
PII: Masked in logs; usernames hashed for indexing.
SECRET ACCESS: SAML IdP certificates and SCIM bearer tokens stored securely.
EXTERNAL ACTION: Prohibited.
DEFAULT: DENY.

## Operational behavior

RETRY: SCIM requests honor `ETag` / optimistic concurrency controls.
TIMEOUT: SAML validation $< 25\text{ms}$; SCIM request processing $< 100\text{ms}$.
IDEMPOTENCY: SCIM PATCH operations are idempotent by version counter.
LOGGING: Structured audit events `identity.saml.acs_success` and `identity.scim.user_deactivated`.
METRICS: `identity.saml.requests_total`, `identity.scim.deprovision_duration_ms`.
FAILURE BEHAVIOR: SAML signature failure rejects user login; SCIM conflict returns 409.
