class SecretRotationService:
    def initiate_rotation(self, tenant_id: TenantId, secret_ref: SecretReference) -> RotationSession: ...
    def validate_and_commit_rotation(self, session_id: str) -> None: ...
    def rollback_rotation(self, session_id: str, reason: str) -> None: ...

MUST NOT: Expose raw secret values to callers, log plaintext tokens, or fallback to unverified keys during broker outages.

## Input/output and validation

INPUT: `tenant_id`, `SecretReference`, requested action scope, provider audience.
OUTPUT: Short-lived `EphemeralProviderToken` ($\le 60\text{min}$ TTL) valid only for target provider and scope.
INVALID INPUT: Mismatched tenant ownership, revoked secret reference, scope expansion attempt.
VALIDATION RULES: Scopes must strictly subset registered provider permissions.
STATE TRANSITIONS: Secret rotation transitions through `ACTIVE` $\to$ `ROTATING` $\to$ `ACTIVE`.

## Security contract

AUTHENTICATION: Internal workload identity / mTLS.
AUTHORIZATION: Scope-bounded and tenant-isolated.
TENANT: Partitioned by `tenant_id`; cross-tenant key resolution blocked.
PII: Prohibited.
SECRET ACCESS: Strictly controlled; memory-only ephemeral token cache.
EXTERNAL ACTION: Governed via Tool Gateway.
DEFAULT: DENY.

## Operational behavior

RETRY: Ephemeral token fetch retries up to 2 times with jitter on transient 503.
TIMEOUT: Secret resolution $< 50\text{ms}$; external token exchange $< 2000\text{ms}$.
IDEMPOTENCY: Rotation commit operations are idempotent by session ID.
LOGGING: Emits `security.secret.rotated`, `security.secret.revoked` (NO secret values).
METRICS: `security.secrets.cache_hit_ratio`, `security.secrets.rotation_duration_ms`.
FAILURE BEHAVIOR: Secret store outage causes all downstream dispatches to fail closed (`INV-REL-001`).
