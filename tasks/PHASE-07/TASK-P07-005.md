INPUT: Provider descriptor, tenant ID, capability type, secret reference.

INVALID INPUT: Empty scopes, unregistered provider name, or missing secret reference.
VALIDATION RULES: Scopes must strictly match provider capability manifest.

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `CONNECTOR_NOT_FOUND` | Unknown connector ID | 404 | no | Connector not found | yes | `connectors.errors` |
| `INVALID_SCOPE` | Scope not permitted | 422 | no | Requested scopes exceed policy | yes | `connectors.errors` |
| `AUTH_EXPIRED` | 401/403 from provider | 401 | no | Integration authentication expired | yes | `connectors.auth_expired` |
| `RATE_LIMITED` | 429 from provider | 429 | yes | Provider rate limit reached | yes | `connectors.degraded` |

## Security contract

AUTHENTICATION: Requires `tenant_admin` or internal ingestion worker.
AUTHORIZATION: Scoped strictly per tenant.
TENANT: Hard tenant isolation; connectors cannot span multiple tenants.
PII: Prohibited in cursor state and health logs.
SECRET ACCESS: Via `SecretReference` and `SecretBrokerPort`.
EXTERNAL ACTION: Read-only sync only.
DEFAULT: DENY.

## Operational behavior

RETRY: Connectivity canary retries twice on transient network timeout.
TIMEOUT: Health check canary timeout 10 seconds.
IDEMPOTENCY: Checkpoints and state transitions are transactional.
LOGGING: Emits structured event `connector.activated` and `connector.auth_expired`.
METRICS: `connector.status_gauge`, `connector.sync.lag_seconds`.
FAILURE BEHAVIOR: Consecutive 401 errors transition connector to `AUTH_EXPIRED` and halt sync.
