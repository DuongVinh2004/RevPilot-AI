## Symbol-level contract

### `packages/backend/src/revpilot/shared/identifiers.py`

- MUST EXPORT:
  - `EntityId(value: str)`
  - `TenantId(value: str)` (default prefix `tnt_`)
  - `PrincipalId(value: str)` (default prefix `usr_`)
  - `OrganizationId(value: str)` (default prefix `org_`)
  - `InvestigationId(value: str)` (default prefix `inv_`)
  - `EvidenceId(value: str)` (default prefix `evd_`)
  - `ActionId(value: str)` (default prefix `act_`)
  - `ApprovalId(value: str)` (default prefix `app_`)
- Invariants:
  - Immutable (`@dataclass(frozen=True)` or similar).
  - Rejects empty, whitespace-only, or invalid strings.
  - Generates deterministic/random prefixed IDs with `.generate()`.
  - Equality and hash support for use in dict/set.

### `packages/backend/src/revpilot/shared/temporal.py`

- MUST EXPORT:
  - `UtcDateTime`
    - `.now() -> UtcDateTime`
    - `.from_iso(iso_str: str) -> UtcDateTime`
    - `.from_datetime(dt: datetime) -> UtcDateTime`
    - `.isoformat() -> str`
    - `.value: datetime` (guaranteed `tzinfo=timezone.utc`)
  - `TimeWindow`
    - `start: UtcDateTime`
    - `end: UtcDateTime`
    - Invariant: `start <= end`
    - `.contains(dt: UtcDateTime) -> bool`
    - `.duration_seconds() -> float`
- Invariants:
  - Strictly rejects naive `datetime` objects without timezone or with non-UTC timezone without conversion.

### `packages/backend/src/revpilot/shared/monetary.py`

- MUST EXPORT:
  - `Currency(Enum)`: ISO-4217 uppercase 3-letter codes (`USD`, `EUR`, `GBP`, `JPY`, etc.).
  - `Money`
    - `amount: Decimal`
    - `currency: Currency`
    - Rejects `float` initialization.
    - Supported operations: `add`, `subtract`, `multiply`, `==`, `<`, `<=`, `>`, `>=`.
    - Invariant: Mismatched currency arithmetic raises `ValueError`.

## Input/output and validation

- IDs: max length 64 characters, ASCII alphanumeric with optional prefix.
- UTC: strictly timezone-aware UTC datetime. Naive datetime raises `ValueError`.
- Money: exact `Decimal` precision. Float input raises `TypeError`. Mismatched currency raises `ValueError`.

## Security and tenancy contract

- IDs prevent type confusion between different entity types (e.g., `TenantId` cannot be accidentally used where `InvestigationId` is expected).
- Zero external dependencies beyond Python standard library.
