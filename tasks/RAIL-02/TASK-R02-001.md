## Symbol-level contract

MUST EXPORT/DEFINE:
1. `TenantStatus(str, Enum)`:
   - `PROVISIONING = "provisioning"`
   - `ACTIVE = "active"`
   - `SUSPENDED = "suspended"`
   - `DEACTIVATED = "deactivated"`
2. `SubscriptionTier(str, Enum)`:
   - `SHARED = "shared"`
   - `ENTERPRISE = "enterprise"`
   - `REGULATED = "regulated"`
3. `Entitlement`:
   - Attributes: `tier: SubscriptionTier`, `max_seats: int`, `features: frozenset[str]`, `quotas: dict[str, int]`
   - Method: `has_feature(feature_name: str) -> bool`
   - Method: `get_quota(quota_name: str, default: int = 0) -> int`
4. `Organization`:
   - Attributes: `id: OrganizationId`, `name: str`, `created_at: UtcDateTime`, `is_active: bool = True`
5. `Tenant`:
   - Attributes: `id: TenantId`, `organization_id: OrganizationId`, `name: str`, `status: TenantStatus`, `tier: SubscriptionTier`, `entitlement: Entitlement`, `created_at: UtcDateTime`, `updated_at: UtcDateTime`
   - Method: `is_active() -> bool`
   - Method: `activate() -> None` (prohibited if deactivated/terminal)
   - Method: `suspend(reason: str) -> None` (requires non-empty reason)
   - Method: `deactivate() -> None`
   - Method: `to_context() -> TenantContext` (fails closed if not active)

MUST NOT:
- Depend on infrastructure, databases, network libraries, or external frameworks.
- Depend on business modules (investigations, actions, billing, etc.).

## Input/output and validation

- `TenantStatus` and `SubscriptionTier` string conversions must be exact and lowercase.
- `Tenant` name cannot be empty or blank.
- Transitioning from `DEACTIVATED` to any status raises `ValidationError` (deactivation is terminal).
- Transitioning to `SUSPENDED` without reason raises `ValidationError`.
- Calling `to_context()` on a non-active tenant raises `TenancyViolationError`.
