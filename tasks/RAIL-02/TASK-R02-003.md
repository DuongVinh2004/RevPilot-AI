## Symbol-level contract

MUST EXPORT/DEFINE:
1. `InMemoryTenantRepository`:
   - Implements `TenantQueryPort` and `TenantCommandPort`.
   - `get_by_id(tenant_id: TenantId) -> Tenant | None`
   - `get_by_organization(organization_id: OrganizationId) -> list[Tenant]`
   - `get_organization_by_id(organization_id: OrganizationId) -> Organization | None`
   - `exists(tenant_id: TenantId) -> bool`
   - `save_tenant(tenant: Tenant) -> None`
   - `save_organization(organization: Organization) -> None`
   - `update_status(tenant_id: TenantId, status: TenantStatus, reason: str | None = None) -> Tenant`
2. `TenantService`:
   - `create_organization(name: str, org_id: OrganizationId | None = None) -> Organization`
   - `provision_tenant(organization_id: OrganizationId, name: str, tier: SubscriptionTier = SubscriptionTier.SHARED, entitlement: Entitlement | None = None, tenant_id: TenantId | None = None) -> Tenant`
   - `activate_tenant(tenant_id: TenantId) -> Tenant`
   - `suspend_tenant(tenant_id: TenantId, reason: str) -> Tenant`
   - `deactivate_tenant(tenant_id: TenantId) -> Tenant`
   - `resolve_tenant_context(tenant_id: TenantId) -> TenantContext`
   - `resolve_security_context(tenant_id: TenantId, principal: PrincipalContext) -> SecurityContext`

MUST NOT:
- Depend on real database, network clients, or external frameworks.
- Allow context generation for inactive or non-existent tenants.

---

## Input/output and validation

- `provision_tenant` checks that `organization_id` exists; raises `NotFoundError` if missing.
- `update_status` on non-existent `tenant_id` raises `NotFoundError`.
- `resolve_tenant_context` on non-existent `tenant_id` raises `NotFoundError`.
- `resolve_tenant_context` on inactive tenant raises `TenancyViolationError` (fail-closed).
- `resolve_security_context` with cross-tenant user principal raises `TenancyViolationError`.
