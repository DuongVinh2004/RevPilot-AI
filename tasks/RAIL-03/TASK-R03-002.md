## Symbol-level contract

MUST EXPORT/DEFINE:

1. `VerifiedSessionEvidence`:
   - Immutable typed evidence object for session state (`dataclass(frozen=True, slots=True)`).
   - Attributes:
     - `session_id: str`
     - `is_active: bool`
     - `is_revoked: bool`
     - `issued_at: UtcDateTime`
     - `expires_at: UtcDateTime`
     - `_provenance_signature: str`
   - Factory: `issue(...)` computing cryptographic provenance proof.
   - Rejects unverified caller payloads or invalid signatures with `AuthenticationError`.

2. `SessionPolicy`:
   - Domain policy enforcing session lifecycle and revocation rules.
   - Method: `validate_session_evidence(evidence: VerifiedSessionEvidence, as_of: UtcDateTime | None = None) -> None`:
     - Raises `AuthenticationError` if `evidence.is_revoked` is True ("Token or session has been revoked").
     - Raises `AuthenticationError` if `not evidence.is_active` ("Session is not active").
     - Raises `AuthenticationError` if `as_of` exceeds `evidence.expires_at` ("Session has expired").
     - Fails closed on any invalid or unverified evidence.
     - Primitive caller booleans (`is_revoked: bool`) are NEVER accepted as trust anchors.

3. `TokenValidationPolicy`:
   - Attributes: `expected_issuer: str = "revpilot-idp"`, `expected_audience: str = "revpilot-api"`, `clock_skew_seconds: int = 60`.
   - Validates `0 <= clock_skew_seconds <= 60`; rejects negative or >60 values with `ValidationError`.
   - Method: `validate_verified_token(verified: VerifiedClaimsToken, as_of: UtcDateTime | None = None) -> None`:
     - Strictly requires `VerifiedClaimsToken`; rejects raw/unverified claims with `TypeError`.
     - Raises `AuthenticationError` if `verified.claims.iss != expected_issuer` or `verified.verified_issuer != expected_issuer` ("Invalid token issuer").
     - Raises `AuthenticationError` if `verified.claims.aud != expected_audience` or `verified.verified_audience != expected_audience` ("Invalid token audience").
     - Raises `AuthenticationError` if `as_of >= (verified.claims.exp + clock_skew_seconds)` ("Token has expired").
     - Raises `AuthenticationError` if `verified.claims.nbf is not None` and `as_of < (verified.claims.nbf - clock_skew_seconds)` ("Token not yet active").
     - Enforces non-system tenant association (`INV-TEN-003`).

4. `AuthenticationPort(Protocol)`:
   - Interface defining inbound authentication abstraction:
     - `verify_token(token: str, *, expected_issuer: str = "revpilot-idp", expected_audience: str = "revpilot-api", as_of: UtcDateTime | None = None) -> VerifiedClaimsToken`:
       - Returns typed `VerifiedClaimsToken` evidence. Structurally prohibited from bypassing the verified boundary or directly manufacturing `Principal`.
     - `revoke_session(session_id: str) -> None`:
       - Signals session revocation to the underlying store/ledger.
     - `get_session_evidence(session_id: str, as_of: UtcDateTime | None = None) -> VerifiedSessionEvidence`:
       - Retrieves provenance-bound session evidence for verification.

MUST NOT:
- Accept caller-supplied boolean flags (e.g. `is_revoked: bool`, `is_active: bool`) without provenance proof.
- Return raw `Principal` directly from `AuthenticationPort.verify_token`, bypassing `VerifiedClaimsToken`.
- Implement concrete network calls, OIDC discovery, or external OAuth2 requests.
- Store plain text passwords or secrets (`INV-SEC-001`).
- Allow clock skew exceeding 60 seconds.
