## Symbol-level contract

MUST EXPORT/DEFINE:

1. `IdentityService` (`packages/backend/src/revpilot/modules/identity/service.py`):
   - Constructor:
     ```python
     def __init__(
         self,
         auth_port: AuthenticationPort,
         *,
         token_policy: TokenValidationPolicy | None = None,
         session_policy: SessionPolicy | None = None,
         tenant_query_port: TenantQueryPort | None = None,
         tenancy_policy: type[TenantContextPolicy] | None = None,
     ) -> None
     ```
   - Method `authenticate_token(token: str, as_of: UtcDateTime | None = None) -> Principal`:
     - Step 1: Input validation: `token` must be a non-empty string. Raises `ValidationError` or `AuthenticationError` if empty or invalid.
     - Step 2: Authentication boundary verification: calls `auth_port.verify_token(token, expected_issuer=self._token_policy.expected_issuer, expected_audience=self._token_policy.expected_audience, as_of=as_of)` returning `VerifiedClaimsToken`. Structurally prohibited from receiving raw `Principal` or unverified `AuthTokenClaims`.
     - Step 3: Domain token policy validation: calls `token_policy.validate_verified_token(verified_token, as_of=as_of)`. Enforces expected issuer, expected audience, bounded clock skew (<= 60s), not-before, and non-empty tenant binding.
     - Step 4: Session lifecycle validation: calls `auth_port.get_session_evidence(verified_token.session_id, as_of=as_of)` returning `VerifiedSessionEvidence`. Validates evidence via `session_policy.validate_session_evidence(evidence, as_of=as_of)`. Fails closed with `AuthenticationError("Token or session has been revoked")` if revoked, inactive, or expired.
     - Step 5: Tenant status verification (INV-TEN-001, INV-TEN-002, INV-TEN-003):
       - Parses `tenant_id = TenantId(verified_token.claims.tenant_id)`.
       - If `tenant_query_port` is provided: queries tenant aggregate via `tenant_query_port.get_by_id(tenant_id)`. Raises `TenancyViolationError` if tenant is not found or not active (`tenant.is_active() is False`).
       - If `tenancy_policy` is provided: verifies tenant context via `tenancy_policy.validate_context(tenant.to_context())`.
     - Step 6: Trusted domain entity instantiation: calls `create_principal_from_verified_claims(verified_token, as_of=as_of)` to instantiate aggregate `Principal`.
     - Step 7: Returns verified `Principal`.
   - Method `revoke_session(session_id: str) -> None`:
     - Validates `session_id` is a non-empty string.
     - Delegates to `auth_port.revoke_session(session_id)`.
   - Method `get_session_evidence(session_id: str, as_of: UtcDateTime | None = None) -> VerifiedSessionEvidence`:
     - Validates `session_id` is a non-empty string.
     - Delegates to `auth_port.get_session_evidence(session_id, as_of=as_of)`.

2. `InMemoryAuthAdapter(AuthenticationPort)` (`packages/backend/src/revpilot/modules/identity/adapters/in_memory_auth_adapter.py`):
   - In-memory implementation of `AuthenticationPort` conforming to `@runtime_checkable` protocol.
   - Internal storage:
     - `_tokens: dict[str, VerifiedClaimsToken]`
     - `_sessions: dict[str, VerifiedSessionEvidence]`
     - `_revoked_sessions: set[str]`
   - Protocol method `verify_token(token: str, *, expected_issuer: str = "revpilot-idp", expected_audience: str = "revpilot-api", as_of: UtcDateTime | None = None) -> VerifiedClaimsToken`:
     - Looks up token in `_tokens`. If not found, raises `AuthenticationError("Invalid token signature or token unknown")`.
     - Checks issuer and audience against `expected_issuer` and `expected_audience`; raises `AuthenticationError` on mismatch.
     - Checks if `session_id` is in `_revoked_sessions`; raises `AuthenticationError("Token or session has been revoked")`.
     - Returns `VerifiedClaimsToken`. Structurally prohibited from returning raw `Principal`.
   - Protocol method `revoke_session(session_id: str) -> None`:
     - Validates `session_id` is a non-empty string.
     - Adds `session_id` to `_revoked_sessions`.
     - If `session_id in self._sessions`: updates evidence to revoked (re-issuing `VerifiedSessionEvidence` with `is_revoked=True`).
   - Protocol method `get_session_evidence(session_id: str, as_of: UtcDateTime | None = None) -> VerifiedSessionEvidence`:
     - Validates `session_id` is a non-empty string.
     - If `session_id in self._revoked_sessions`: if present in `_sessions`, returns evidence re-issued with `is_revoked=True`; otherwise raises `AuthenticationError("Token or session has been revoked")`.
     - If `session_id not in self._sessions`: raises `AuthenticationError(f"Session '{session_id}' not found or unverified")`.
     - Returns stored `VerifiedSessionEvidence`.
   - Test registration helpers:
     - `register_token(token_string: str, verified_token: VerifiedClaimsToken, session_evidence: VerifiedSessionEvidence | None = None) -> None`:
       Registers `VerifiedClaimsToken` and optional `VerifiedSessionEvidence`. Requires verified typed evidence with provenance proof; never accepts bare caller-supplied booleans or untyped dicts.
     - `issue_test_token(claims: AuthTokenClaims, session_id: str, ...) -> tuple[str, VerifiedClaimsToken, VerifiedSessionEvidence]`:
       Factory helper to generate valid signed tokens and verified evidence for test suites.

MUST NOT:
- Connect to network, external OIDC endpoints, or remote key servers.
- Store plain text passwords, secrets, or raw credentials as authority.
- Accept bare caller-supplied booleans (`is_revoked: bool`, `is_active: bool`) as trust anchors.
- Return `Principal` from `AuthenticationPort.verify_token`.
- Bypass tenant status verification or allow client-controlled tenant overrides.
- Manufacture privileged system contexts directly.

## Input/output and validation

- Tokens must be non-empty strings.
- Unknown token string raises `AuthenticationError`.
- Revoked session identifier raises `AuthenticationError`.
- Suspended or inactive tenant raises `TenancyViolationError`.
- Missing tenant raises `TenancyViolationError`.

## Error contract

| Code | Trigger | HTTP/status | Retryable | Client-safe message | Audit | Metric |
|---|---|---|---:|---|---:|---|
| `AUTHENTICATION_ERROR` | Unknown token, invalid signature, revoked session, expired token | 401 | no | Token or session has been revoked / Authentication failed | yes | identity.auth.failure |
| `TENANCY_VIOLATION` | Associated tenant is inactive, suspended, or missing | 403 | no | Principal belongs to an inactive or suspended tenant | yes | identity.tenant.violation |
| `VALIDATION_ERROR` | Malformed token parameter or empty string | 400 | no | Invalid token parameter | yes | identity.validation.failure |

## Security contract

- Invariant `INV-IAM-001`: Deny-by-default authentication verification.
- Invariant `INV-TEN-002`: Server-derived context; client cannot override tenant.
- Invariant `INV-TEN-003`: Explicit tenant association required for all user and service account principals.
- Invariant `INV-SEC-001`: Zero credentials or tokens exposed to agent runtime.
- Invariant `INV-REL-001`: Fail-closed behavior on all authentication, session, or tenant uncertainty.

---

## Tenancy contract

- Ensures that authenticated Principal is bound to an active tenant.
- Fails closed with `TenancyViolationError` if tenant is suspended, deactivated, or missing.
- Prevents cross-tenant bypass or client tenant tampering.
