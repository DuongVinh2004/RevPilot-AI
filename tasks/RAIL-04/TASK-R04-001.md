## Symbol-level contract

MUST EXPORT/DEFINE:
1. `Permission`:
   - Immutable value object (`dataclass(frozen=True, slots=True)`).
   - Attributes: `resource: str`, `action: str`.
   - String format: `f"{resource}:{action}"`.
   - Method: `matches(required: Permission) -> bool`:
     - Returns True if `self.resource == required.resource` and (`self.action == required.action` or `self.action == "*"`).
     - Returns True if `self.resource == "*"` (wildcard).
   - Classmethod: `from_string(val: str) -> Permission`:
     - Parses `"resource:action"` string. Raises `ValidationError` if format invalid.
2. `Role`:
   - Immutable value object (`dataclass(frozen=True, slots=True)`).
   - Attributes: `name: str`, `permissions: frozenset[Permission]`, `description: str = ""`
   - Method: `has_permission(permission: Permission) -> bool`:
     - Checks if any granted permission matches `permission`.
3. `StandardRoles`:
   - Role registry factory providing canonical roles:
     - `PLATFORM_ADMIN`: Role with wildcard permission `*:*`.
     - `TENANT_ADMIN`: `tenant:manage`, `user:manage`, `investigation:*`, `evidence:*`, `audit:read`, `policy:read`.
     - `OPERATOR`: `investigation:create`, `investigation:read`, `evidence:read`, `tool:invoke`, `approval:request`.
     - `ANALYST`: `investigation:read`, `evidence:read`, `analytics:read`, `audit:read`.
     - `AUDITOR`: `audit:read`, `compliance:read`, `investigation:read`, `evidence:read`.
     - `AGENT_DELEGATE`: `investigation:read`, `evidence:read`, `tool:invoke`.
   - Method: `get_role(name: str) -> Role`:
     - Looks up standard role by lowercase name. Raises `ValidationError` if unknown.
4. `PolicyAttributes`:
   - Immutable ABAC attributes value object (`dataclass(frozen=True, slots=True)`):
     - `tenant_id: TenantId`
     - `resource_id: str | None = None`
     - `resource_tenant_id: TenantId | None = None`
     - `task_id: str | None = None`
     - `as_of: UtcDateTime | None = None`

MUST NOT:
- Implement hardcoded database queries or network lookups.
- Allow empty resource or action in `Permission`.

## Input/output and validation

- Permission string must contain exactly one colon (`:`); neither resource nor action may be empty.
- Role name must be lowercase alphanumeric string with underscores.
- Unknown role name in `StandardRoles.get_role` raises `ValidationError`.
