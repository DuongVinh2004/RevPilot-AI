## Symbol-level contract

MUST EXPORT/DEFINE:
1. `DelegationToken`:
   - Immutable value object (`dataclass(frozen=True, slots=True)`):
     - `delegation_id: str` (e.g. `del_...`)
     - `delegator_id: PrincipalId`
     - `tenant_id: TenantId`
     - `task_id: str`
     - `allowed_capabilities: frozenset[Permission]`
     - `target_resources: frozenset[str]`
     - `issued_at: UtcDateTime`
     - `expires_at: UtcDateTime`
     - `revocation_version: int = 1`
   - Method: `is_expired(as_of: UtcDateTime | None = None) -> bool`:
     - Compares `as_of` (defaults to now) against `expires_at`.
   - Method: `allows_capability(capability: Permission) -> bool`:
     - Checks if any allowed capability matches `capability`.
   - Method: `allows_target(resource: str) -> bool`:
     - Checks if `resource` matches any target in `target_resources`.
     - Target matching rules:
       - Exact match: `resource == target`.
       - Safe segment-boundary prefix match: `resource.startswith(f"{target}/")` or `resource.startswith(f"{target}:")`, or if `target` ends with `/` or `:`, `resource.startswith(target)`.
       - Wildcard suffix `/*`: if target ends with `/*`, matching prefix requires `resource.startswith(target[:-1])`.
       - Fail-closed: Arbitrary string prefixes without segment boundaries (e.g. `/tenant/a` matching `/tenant/abc`) are strictly prohibited and return `False`.
2. `issue_delegation(delegator: Principal, tenant_id: TenantId, task_id: str, capabilities: frozenset[Permission], target_resources: frozenset[str], duration_seconds: int = 3600, as_of: UtcDateTime | None = None) -> DelegationToken`:
   - Factory enforcing delegation invariants:
     - `delegator` cannot be of type `AGENT` (agents cannot sub-delegate).
     - `duration_seconds` must be between 60 and 86400 (max 24 hours); raises `ValidationError` otherwise.
     - `capabilities` cannot be empty.
     - Enforces `INV-ACT-003`: `capabilities` CANNOT contain `approval:grant` or `approval:*`. Raises `AuthorizationError("Delegated agents cannot receive approval authority")`.
     - Enforces `INV-IAM-002`: Every requested permission in `capabilities` must be held by `delegator`. If delegator lacks any permission, raises `AuthorizationError("Delegation capability exceeds delegator permissions")`.
     - Generates unique `delegation_id` (`del_...`).
3. `DelegationRevocationRegistry`:
   - Thread-safe in-memory revocation store:
     - `revoke(delegation_id: str, reason: str = "") -> None`
     - `is_revoked(delegation_id: str) -> bool`

MUST NOT:
- Permit delegation of approval permissions (`INV-ACT-003`).
- Allow duration exceeding 24 hours (86,400 seconds).
- Grant API keys or raw credentials in `DelegationToken`.

## Security contract

- Invariant `INV-IAM-002`: Delegation cannot exceed delegator scope.
- Invariant `INV-ACT-003`: Agents cannot hold approval rights.
- Invariant `INV-SEC-001`: Delegation token carries permissions, never credentials.

## Tenancy contract

- Delegation strictly binds to `tenant_id` matching delegator's tenant context.
- Cross-tenant delegation is prohibited.
