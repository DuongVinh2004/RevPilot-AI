## Symbol-level contract (Remediated)

MUST EXPORT/DEFINE:
1. Canonical `PrivilegedContext` (from `packages.backend.src.revpilot.modules.identity.domain.models`):
   - Opaque immutable value object with cryptographic platform provenance signature (`_provenance_signature`).
   - No public caller constructor; cannot be manufactured from strings.
   - Validated via `context.is_valid(as_of)`.
2. `AuthorizationPort(Protocol)`:
   - `authorize_principal(principal: Principal, resource_tenant_id: TenantId, permission: Permission, attributes: PolicyAttributes | None = None) -> bool`:
     - Verifies principal tenant binding strictly matches `resource_tenant_id`.
     - Ordinary principals cannot bypass tenant boundary.
   - `authorize_delegation(token: DelegationToken, resource_tenant_id: TenantId, capability: Permission, target_resource: str, as_of: UtcDateTime | None = None) -> bool`:
     - Verifies delegation tenant binding matches `resource_tenant_id`.
     - Verifies token is not expired and not revoked.
     - Verifies allowed capability and target resource matching safe segment boundary.
   - `authorize_privileged(context: PrivilegedContext, permission: Permission, attributes: PolicyAttributes | None = None, as_of: UtcDateTime | None = None) -> bool`:
     - Separate, explicit boundary for verified platform operations (`INV-TEN-003`).
     - Verifies `context.is_valid(as_of)`. Fails closed if invalid or expired.
3. `AuthorizationService(AuthorizationPort)`:
   - Implements `AuthorizationPort`.
   - Rejects null tenant on tenant-owned resources.
   - Fail-closed evaluation: any exception, uncertainty, or missing parameter denies access (`INV-REL-001`).
   - Helper `assert_authorized(principal: Principal, resource_tenant_id: TenantId, permission: Permission) -> None` raising `AuthorizationError`.

MUST NOT:
- Provide a public constructor or factory allowing callers to self-elevate to privileged system context.
- Permit wildcard permissions or standard roles to cross tenant boundaries without verified `PrivilegedContext`.
- Permit autonomous agents to assume `PrivilegedContext`.
