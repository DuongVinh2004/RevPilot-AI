## Symbol-level contract

MUST EXPORT/DEFINE:
1. `TenantScopedEntity(Protocol)`:
   - Protocol requiring:
     - `tenant_id: TenantId`
     - `id: str`
2. `TenantScopedRepositoryPort(Protocol[T])`:
   - Generic repository interface over `T: TenantScopedEntity`:
     - `get_by_id(context: TenantContext, id: str) -> T | None`:
       - Must reject null or inactive context with `TenancyViolationError`.
     - `save(context: TenantContext, entity: T) -> None`:
       - Must verify `context.tenant_id == entity.tenant_id` (unless `context.is_system`). Raises `TenancyViolationError` on mismatch.
     - `delete(context: TenantContext, id: str) -> None`:
       - Must reject null or inactive context with `TenancyViolationError`.
     - `list_by_tenant(context: TenantContext, limit: int = 100, offset: int = 0) -> Sequence[T]`:
       - Must enforce tenant scoping.
3. `AggregateOwnershipRegistry`:
   - Registry enforcing single-module write ownership (`INV-DATA-002`):
     - `register(aggregate_type: str, owning_module: str) -> None`:
       - Registers ownership. If `aggregate_type` is already registered to a different module, raises `ValidationError("Aggregate already owned by different module")`.
     - `get_owner(aggregate_type: str) -> str`:
       - Returns owning module name. Raises `ValidationError` if unowned.
     - `assert_owner(aggregate_type: str, calling_module: str) -> None`:
       - Raises `AuthorizationError` if `calling_module != get_owner(aggregate_type)`.

MUST NOT:
- Permit repository operations with `context = None`.
- Allow multi-module write ownership for any aggregate.
- Connect to network or external database in shared kernel.

## Input/output and validation

- Context passed to repository ports must be an instance of `TenantContext`.
- Context must be active (`context.is_active == True`) or system privileged (`context.is_system == True`).
- Entity tenant_id and context tenant_id must strictly match.
