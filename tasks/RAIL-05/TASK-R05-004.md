## Symbol-level contract

MUST TEST/VERIFY:
1. `INV-TEN-001`: Null or missing tenant context returns 0 rows or raises `TenancyViolationError`.
2. Cross-Tenant Read Isolation: Querying Tenant B records from Tenant A context returns `None` or raises `EntityNotFoundError`.
3. Cross-Tenant Write Isolation: Attempting to save Tenant B records from Tenant A context raises `TenancyViolationError`.
4. Cross-Tenant Delete Isolation: Attempting to delete Tenant B records from Tenant A context fails closed without affecting Tenant B.
5. Composite Key Enforcement: Composite key mismatch raises validation error.
6. RLS Session State Isolation: Connection checkout resets and re-establishes session context cleanly, preventing connection pool leaks.
7. Privileged Operations (`INV-TEN-003`): Platform maintenance tasks explicitly set `is_system=True` and cannot access data with unverified `tenant=None`.
8. Expand/Contract Migration Enforcement: Prohibited DDL modifications (drop column, in-place rename, not-null without default) are rejected by migration safety validator.
